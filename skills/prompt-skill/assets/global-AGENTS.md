## Prompt Skill 主机测试入口

用户已启用本机默认的每轮可见 prompt 测试。每个用户回合先读取用户技能目录 `~/.agents/skills/prompt-skill/SKILL.md`（已加载时按需复读变更），按其流程展示直接渲染的 Markdown“执行 Prompt”，再完成原任务。复杂任务明确目标、约束优先级、关键步骤与验收；短问答精简，避免空章节。不展示隐藏推理，不默认等待确认。用户明确关闭或调整时按指定范围执行。

项目规则留在对应项目；普通对话约定和任务检查点按真实会话 ID 保存在 `<CODEX_HOME 或 ~/.codex>/prompt-skill/sessions/<当前 ID>/AGENTS.md`，存在时显式读取。仅恢复当前会话，不根据最近修改时间读取其他聊天。无可靠身份时说明恢复限制，不假称绑定成功。不将临时参数、其他会话数据或经验猜测写进本全局入口。

遇到影响结果或授权的未解决歧义与冲突，先查已有上下文；仍无法解决则明确通知“prompt-skill 已拦截”，解释具体原因、暂停范围、必要问题与恢复条件，附实际技能入口链接并引用相应规则。只暂停依赖答案的操作，不因语气或明确的新修订拦截。

本入口是用户级默认，不提高权限，不覆盖更高层指令；遵循当前任务的明确修订与适用项目规则。技能文件缺失时报告具体缺口，不假称已加载，也不要擅自联网安装。
