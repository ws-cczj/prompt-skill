# prompt-skill

执行前，把当前请求与相关对话整理成用户可见的执行 prompt，检查上下文限制、优先级和适用经验，再完成原任务。

## 执行线路

分析语境 → 识别目的 → 提取限制 → 排列优先级 → 生成初稿 → 经验检查 → 复核并生成最终 prompt → 展示 → 执行。

目的不明确时区分事实与假设；同一事项的新修订替换旧值，其他有效限制继续保留。只展示最终任务说明，无须展示内部推理或等待逐轮确认。

测试 prompt 使用直接渲染的 Markdown：目标与交付物 → 相关语境与输入 → 优先级与约束（必须满足 / 尽量满足 / 可调整假设）→ 执行步骤 → 验收标准 → 必要的待确认项。简单请求精简展示，避免空章节。

## 项目文件

- [`SKILL.md`](SKILL.md)：技能入口和执行线路。
- [`experiences/index.md`](experiences/index.md)：本地经验索引与记录规则。
- [`experiences/cases.md`](experiences/cases.md)：PPT、图片和多轮约束的初始待验证场景。
- [`AGENTS.md`](AGENTS.md)：本项目每轮先展示 prompt 的测试约定。
- [`references/rule-sync.md`](references/rule-sync.md)：项目与会话规则同步、修订及长对话恢复约定。

一个仓库就是一个 skill，目录结构如下：

```text
prompt-skill/
├── SKILL.md
├── README.md
├── AGENTS.md
├── agents/
├── assets/
├── experiences/
└── references/
```

## 使用

将仓库克隆到目标环境的技能目录，例如 `~/.agents/skills/prompt-skill`，根目录即技能入口。已有目录时先检查差异，不覆盖本地修改。手动安装时只复制版本控制中的技能文件，不带入本地测试、会话记录或运行输出。

```text
使用 $prompt-skill，开启本会话的每轮可见 prompt 测试。
结合相关上下文展示最终执行 prompt，再继续完成我的原任务。
```

默认展示后继续执行；要只看文本或先确认，可明确说“仅生成 prompt”或“确认后执行”。需要复用技能文件时说“将这些需求生成 SKILL.md”。

执行前发现会影响结果的未解决歧义或冲突时，明确通知“prompt-skill 已拦截”，说明具体问题、影响、暂停范围和恢复条件，并提出必要问题。用户不满或反复纠正时加强复核；清楚的新修订和情绪本身不触发拦截。确认关键缺口后更新 prompt 并恢复，独立部分可继续。

测试约定在当前会话持续生效，用户可随时关闭。本仓库的 AGENTS.md 用于项目内持续测试；其他环境需要加载技能并开启测试模式。主机级默认模式需用户明确安装下述入口，普通任务不会自行改写全局设置。

经验按待验证、已观察、已验证、已失效区分；初始场景尚无行为测试结果，不能视为已验证规则。

收到历史对话数据后，可逐轮回放生成 prompt、检查遗漏并积累经验。回放只使用当轮可见的上下文，历史命令作为测试资料，不自动执行。

## Agent 规则同步

整理 prompt 时同步提取明确的持续约束：项目级规则合并到项目 `AGENTS.md`，普通聊天及会话专属规则保存在仓库外、按真实会话 ID 隔离的 `AGENTS.md` 快照中。单次任务参数只进入任务检查点，不提升为项目规则；修改和撤销按属性更新。

每轮显式读取匹配的规则快照，维持精简的有效规则、来源和下一步。会话快照是本技能的回退设计，需要已加载的技能或入口引导读取；不承诺未配置入口的聊天会自动恢复。

## 主机级测试安装

1. 将本仓库克隆到 `~/.agents/skills/prompt-skill`。目标存在时先检查差异，不覆盖本地改动。开发环境也可使用指向仓库根目录的符号链接或 Windows 目录联接，便于同步更新。
2. 仅在用户明确要求全机默认测试时，将 [全局入口模板](assets/global-AGENTS.md) 合并到 `<CODEX_HOME 或 ~/.codex>/AGENTS.md`。保留已有内容；存在 `AGENTS.override.md` 时先确认实际有效入口，避免写入被忽略的文件。
3. 新开会话检查技能可发现、入口被读取、每轮展示 Markdown prompt。现有会话不能仅凭文件写入就断言已热加载。

技能发现不等于每次调用；全局入口用于明确默认行为。用户说“本轮不展示”“本会话关闭”或“关闭主机测试”时按其范围调整，不扩大撤销范围。配置仅作用于安装它的用户环境，不改变模型权重。

会话明细和测试输出仅保存在本地；`evaluations/`、`tests/` 和 `test/` 均由 Git 忽略。推送仅包含技能、通用经验及说明。

## 验证状态

已完成结构检查、主机入口加载检查，以及明确修订、技能输入分工、缺少文档时拦截三个场景的行为检查。详细测试记录仅留本地，不随技能发布。这些结果不等于长对话性能或全部历史会话回放通过。
