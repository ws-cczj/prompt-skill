# 历史会话回放约定

1. **筛选范围**：按真实会话 cwd 或可靠项目归属筛选，排除用户指定的项目。活跃与归档列表分页到末尾；不能用文件夹里的交接文档冒充完整聊天。统计记录数、去重回合数及未读分页，明确工具读取上限和附件不可见的限制。
2. **保留消息顺序**：一个回合可能包含用户在 agent 执行中追加的多条消息。用回合末所有用户信息重构时标记“回合末重构”，不能声称最初响应应预知后续追加；做在线回放时则按每次消息到达分别更新。
3. **隔离未来反馈**：回放输入截止点与后续评估证据分开。已读过完整会话的人工重构不能称为盲测；如需验证改进，使用独立隔离输入的后续评估。历史附件或技能的当前版本不等于当时版本，不能用最新规则追责早期响应。
4. **分支与重复**：相同回合 ID 的共享历史去重，不把分叉会话当独立训练和验证集；相同标题或同一论文的不同会话保持独立状态。除非用户明确跨会话移交，不将别的会话规则导入。
5. **记录证据级别**：分别标记用户报告、历史 assistant 声明、本次源文件观察和独立复测。只看到旧回复“测试通过”不能宣布产物正确；没有完成回复也不等于任务失败。记忆与正文一致不构成事实验证。
6. **控制存储与授权**：原项目、会话规则和产物只读；本次回放的规则增量存入测试记录，而非写回历史项目。会话级细节保存在本地忽略目录或仓库外，敏感配置与凭据不进入报告；通用经验仅保存必要且去标识化的摘录。
7. **如实报告覆盖**：区分分页获取、逐轮阅读、代表轮次 prompt 重构、全部消息回放、实际业务复现和对策验证。不用生成文件数量替代质量或通过率。长任务维护已处理清单与下一步，不能把未处理轮次宣称完成。

针对视觉类任务，回放可以检查 prompt 是否要求语义与视觉验收；没有打开对应图片或软件时，不能宣布图正确或具体错误已经重现。用户要求的“学习/训练”在本流程中指案例分析与技能改进，不涉及模型权重训练。

使用公开评估集时，记录数据版本或下载摘要、来源ID、许可和筛选方法。公开test样本一旦用于选择改法，只算开发材料，不再称独立留出测试。将输入消息与评分答案分开交给执行者；评估prompt转换时检查约束保留、误增要求与多余拦截，不能直接套用针对业务答案的原始分数。比较旧版与新版时保留旧文件、同一夹具及实际输出；没有对照或样本不足时不宣称提升百分比。外部skill只作方法参考，许可未核实则不复制其正文或执行其脚本。
